# Prototype 0 下游壓力修改與平衡比較

日期：2026-10-07。固定地圖、固定主要流向、0.5 秒步長與雙緩衝保留；沒有隨機／次要流向，沒有 Prototype 1 系統。

## 結果與尚未達成之處

一般降雨下，A～D 與普通城市均無有害淹水。強豪雨下，多條路徑會因下游承載受限而積水，非低窪也能淹水。森林／公園、下凹公園、調節池能減少峰值自由地表水與有害淹水，且 C／D 的河川峰值延後。滯洪容量、入滲與釋水參數均未提高。

仍未完整達成兩個設計方向：有限位置的設施沒有延後全城第一個有害積水／淹水，因未經它們的低窪路徑仍先出問題；極端長雨後 C／D 改善縮小，D 的最高河川水量略高於 A，而不是所有指標都變好。沒有把這些現象隱藏在驗收結論中。

## 新規則

1. 先做本格降雨、乾燥、入滲與設施填水，再凍結受水格的空間／壓力快照。
2. 地表水與設施釋水提出傳送需求；所有指向同一格的來源共享接收空間，按需求比例分配。接收端已積水／河川高水位時，傳送比例下降。沒有借用本步尚未發生的出流空間。
3. 只扣除被接收的水；被拒絕的地表水與蓄水留在來源。河道逐段傳水同樣受下一段壓力限制。
4. 既有固定兩岸溢水在主要傳水後規劃，沿用同一步快照，使用河岸格剩餘接收額度。沒有新增流向。
5. 全部傳入量最後才合併。到達的水可以直接填入設施尚有的容量，但不能在同一步再入滲、釋水或流到下一格。這避免把等著進空水池的水短暫錯標成災害。

地表接收能力只限制外來傳水，不裁切本格降雨、不删除超額水。水量守恆與拆除／替換保留水量仍成立。

## 水量與受災語意

- intentional storage：實際位於各設施容量內的 storage，包含公園、森林、下凹公園與調節池。未增加濕地等新設施。
- free surface：所有陸地的 surface，與設計蓄水、土壤、河川水分開。沒有蓄水設施時也可能有低於安全門檻的薄水，這不算受災。
- harmful ponding：自由地表水達積水門檻、尚未達淹水門檻的格數。
- harmful flooding：自由地表水達淹水門檻的格數。住宅／工業／道路列 urban；綠地／蓄水設施容量外的超安全水列 facility overflow，不把它們整格豁免。
- 各自最大積水與淹水可能不在同一步，不能相加當成最大同時受影響格數。
- 河川「高水位」指水量高於安全容量；「溢岸」表示本步確有轉移到兩岸的水，不再把兩者混用。

## 解讀與限制

1. 不再只有lowland能淹，強豪雨A出現非低窪有害淹水，極端雨則沿多條固定路徑擴大。低窪仍先出問題、平均自由水更深且退水較慢。
2. B／C／D強豪雨效果明确；C／D容量不變也可降低峰值、減少有害淹水並延後河川洪峰。
3. 第一個全城有害積水／淹水時間仍相同：原配置只有部分路徑經過設施，未保護格的第一個局部問題不會被消除。強豪雨中首次非低窪淹水有所延後，完整時間見表。
4. 長雨後設施滿水，保護效果下降。C／D最後的河川洪峰仍在70秒；D的河川峰值略高於A，不能聲稱所有長雨指標都改善。D的峰值有害淹水與自由地表水只小幅改善。若後續要更強的長雨效果，需要先試玩再討論容量、恢復或位置；本次不擅自加強。
5. harmful flooding包含都市與設施容量外的不安全自由水；另以同樣保留的都市格（不含B24格及C／D替換格）比較，排除直接移除住宅造成的假保護。強豪雨在這些共同都市格也有改善。
6. 本模型仍是規則型，固定主要路徑不會自由改道。此次已出現多條路徑超載，沒有加入deterministic secondary path。

## 驗證與使用

21項自動測試通過，涵蓋受水壓力、受阻釋水、共享接收額度、公平分配、遍歷順序、單步不跨格串流、入池不誤標災害、連續雨／退水守恆、非負與有限水量、拆除保留水量、設施數值／地圖未擅自加強、河川高水位與實際溢岸語意、三種雨程平衡。全部控制實驗逐步水量守恆誤差小於1e-6相對單位。
