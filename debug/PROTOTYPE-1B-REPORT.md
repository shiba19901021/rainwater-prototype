## 3–5. 污水分配、容量與排河

採全市抽象污水收集池，沒有管線或服務距離。住宅／工業本步產污與城市取入水所攜帶的污染共同形成待處理負荷。全部處理廠容量加總後，依來源負荷比例分配處理量；多座廠依容量比例分擔，避免迭代順序偏差。超量時只處理容量內部分，剩餘負荷繼續排放。

每個來源未處理負荷送入最近的河川格（曼哈頓距離，相同距離以固定 id 判定），在本地圖通常對應同列河段。實際污水未回收部分也回到河川；已處理但未再利用部分以清水回河。再生水庫存超過緩衝容量時也回河，拆廠不會刪除庫存水。

容量指污染負荷容量，並非另一個獨立污水體積上限。處理比例同時決定實際污水可回收比例。已處理負荷目前視為完全移除，沒有污泥或細分污染種類。

## 6. 河段污染傳遞

原水文只新增記錄「本步真正接受的水量」的觀察 hook，沒有改變流量分配。污染模組使用步初水量與污染快照、實際傳輸紀錄和雙緩衝，以水流比例傳遞污染。抵達下一河段的污染不能在同一步再跨下一段；未接受的水／污染留在來源。

出口污染記入 pollutionOutflow。溢岸水攜帶污染到地表，地表污染也列入帳本，不會因離開河川而消失。取水攜帶的污染進入城市污水，沒有在取水時直接刪除。乾河污染殘留等待後續水流帶走。

## 7. 濕地

濕地優先淨化相鄰河段，再處理自身殘留；合計每步最多 2，超出部分留在水中繼續下游移動。遠離河川不能淨化全河。淨化移除污染質量並記入 pollutionPurified，不消耗／新增河水。正常蓄水使用原 intentional storage 規則，超過安全自由水位才算有害積淹水。

## 8. 再生水

只有實際用水形成的污水，在容量內處理後才能回收。回收水先進有限緩衝庫存，下一步再由供水模組真實扣除使用，不能本步無限循環。預設再生水優先，再用原外部、河川、調節池順序；優先序可調且必須包含四種来源各一次。

完整處理時一輪最多回收 0.7 × 0.5 = 35%，每次循環都損失水。封閉循環測試從 1 份真實水開始，累積用水不超過 1/(1−0.35)，最終耗盡；缺水時產污仍持續，但不會因此制造新水。

## 9–10. 水質限制與狀態

各河段濃度 = 污染質量 / max(1, 地表水＋蓄水)。低於 0.02 為良好，0.02～0.05 受壓，0.05～0.2 污染，0.2 以上嚴重污染。主 UI 顯示最差河段，不是全河平均；詳細資訊保留每段質量、濃度。

取水在 0.02 以下保留原數量能力，0.02～0.12 線性降低，0.12 以上停止。取水安全門檻比「嚴重污染」視覺門檻更嚴格，因此污染級也可能不能取用。原低水位與安全保留水量限制仍共同生效，格子区分「質差」與「低水位」。

河水以藍→灰綠／深灰呈現水質，保留原水位填滿、河岸橙色警示及溢岸動畫。處理廠接近容量／超量標橙色，紅框仍只代表有害淹水。新增四階水質圖例，正常濕地蓄水仍是藍色。

## 14–15. 守恆

水量帳本同時計入真實河川／設施水、再生水庫存、城市消耗、雨量、外部輸入、出口与污水回流。檢核式：

`現存物理水 + 再生水庫存 + (總流出 − 城市內部取水) + 城市總用水 − 污水回流水 − 雨量 − 外部供水 − 開局水 = 0`

城市用水是總用水，所以回流必須扣回，不能當新外部水源重複計入。再生水真實扣庫存，不憑空增加供水。污染帳本式：

`累計新產污 − 處理移除 − 濕地移除 − 出口輸出 − 所有河川／地表殘留 − 暫存的城市攜帶污染 = 0`

pollutionDischarged 是排放通量，包含可能再次進入污水的污染，並非最終消失項，不能與河中剩餘質量一起重複扣除。污染不能隨河水稀釋被直接刪掉。

P1～P8＋12 組啟用洪水比較最大絕對誤差：水量 ≤1.48×10⁻⁸，污染 ≤2.22×10⁻¹⁰，低於驗收容許 10⁻⁷。啟用 W6 水量 2.37×10⁻⁹、污染 9.70×10⁻¹²。各步非負、有限值檢查通過；剩餘差異屬浮點累加。

## 17. 平衡限制與停止點

- 抽象全市污水收集池讓處理廠位置不影響服務範圍；濕地位置有影響。未加入管線或道路服務系統。
- 產污是固定活動負荷，完全缺水後仍產污；污水水量由实际用水決定。缺水時廠可移除乾負荷，但無法據此生成再生水。
- 處理容量以污染負荷為限、處理效率理想化；沒有工程水質種類、病原、污泥或處理時間。
- 濕地每步硬上限，尚無另外的淨化飽和周期；其土壤與蓄水仍使用原飽和机制。
- 乾河濃度使用分母下限 1，數字是相對教學量。溢岸地表殘留有守恆帳本，未做土壤化學／地下水。
- 正式控制面板的自動故事與固定 debug 雨程不同，不應直接比對最終数值。
- 污水回河提高極端洪水範圍，已列明，不自行調回流水比例或舊水文平衡。
- 再生水優先可減少外部使用，但回收非永續；本版沒有水質用途分級。
