# V1 DEVELOPMENT SUMMARY — V1.0｜Core Simulation

封版日期：2026-10-10。基準為已完成並由使用者實際驗收的 Prototype 1C.2。V1 完成的是核心規則型模擬；正式課堂遊戲難度尚未校準。此文件供下一個 Codex／Work 接手。

## 目標與範圍

社區水韌性／水資源城市設計模擬遊戲，服務教師研習。以土地取捨呈現水太多（逕流、洪水、滯洪）、水太少（乾旱、供水、儲水、取水）、水太髒（污染、處理、濕地），連結城市生活需求與衝擊下維持／恢復功能。採規則型、教學型、可視化模擬；不是水利工程、精密水文或城市財務模型。相對水量與壓縮模擬秒不可直接換算實際工程單位。

## 現有水文核心

每格 rainfall 加入自由地表水，按設施入滲與土壤剩餘容量入土；飽和使入滲效率下降，不是永久最大吸水。設計暫存先承接本格水與實際上游來水；池水有限釋放，超容量留在地表。runoff 是傳水速度係數，不是額外生成水量。

陸地固定主要流向至中央河川，河川上游往下游；不做隨機擴散或真實流體。來源傳输同時受來源速度、受水端壓力、剩餘承載量限制；多來源共享同一接收預算，未排出水留在來源。流入量整步合併，因此不會一個 timestep 穿越全圖。河川逐段傳水、出口流出、超量向固定兩岸溢流。低窪仍較早淹、排得慢，但非低窪可因超載積淹水。

自由地表水 surface 與 intentional storage（storage）分開；正常設計蓄水不是災害。有害積淹水由自由水超安全門檻判定，debug 分開統計；綠地容量外的自由水仍可超安全線。1C.2 的 leisure 不因公園承水或容量外洪水扣減，是本版刻意簡化。

## 乾旱與供水

全市需求=sum(facility.waterDemand × 0.04)，按固定步運行。正常開局外部供水 100%、每河段水 30、土壤 45%、調節池容量 50%；水量入 initialWater，不偽稱降雨。少雨逐步累積 droughtStress，25 秒前外部供水不衰減，之後隨壓力漸進下降；有效雨減壓並恢復供水。開局池水有有限保留，城市使用真正消耗，足量雨後恢復原滯洪釋水。

正式污染啟用時水源優先序：再生水 → 外部自來水 → 河川取水 → 調節池。取水站必須正交鄰接河段，受河水量、安全低水位與水質限制，同河段多站公平共享有限水量。調節池兼洪旱但容量有限。供水覆蓋率／缺水比例來自供需，不會憑空補水。重跑重建正常起點；pause/resume 不補資源。

## 污染與污水

住宅／商業／公共服務污染係數 1，工業 3，農地 2，每步乘 0.04。污水採全市抽象收集，無管線；總處理能力為各廠容量之和，按來源負荷比例處理，超額負荷排最近河段。取用的污染水所攜污染也納入處理帳本。城市已供水的 70% 回成污水，已處理比例中的 50% 水轉再生水，下一步可用；其餘水回河，會影響洪水。

污染按實際已接受水流從上游移至下游，出口離開；濃度=污染質量/max(1, surface+storage)，加水稀釋只改濃度，不刪質量。濕地對真正新進自身／相鄰河段的污染按比例且容量有限淨化；靜止污染不反覆洗，同影響區內不再次處理。同河段兩岸分攤同批負荷，不等於兩次串聯；不同河段串聯對殘餘負荷累積。每座每步共用預算，沒有全域上限。

污染守恆帳：generated − treated − purified − outflow − 格子殘留 − carriedLoad。discharged 是內部轉移，不能又當總帳外部損失扣一次。水帳包含初始水、降雨、外部水、污水回流、城市使用、出口及所有在途／再生庫存；使用 supplyMassError／pollutionMassError 原函式，不自行發明重複扣帳。

## 城市生活與韌性

住宅目標 H（預設 12）；jobs=ceil(H)，publicService=ceil(H/3)，leisure=ceil(H/4)。H=12 時需求 12／12／4／3；H=8 時 8／8／3／2。住宅每格 1；商業工作 1；工業 2；農地 1；公共服務 1；一般／下凹／濕地公園休閒 1。超額單項不能補另一需求。

nominal=sum 原配置點數；effective=sum 點數 × currentFunctionFactor。住宅／商業／工業／農地／公共服務受影響；leisure 始終名目。一般格自由水達 3.4／9／13.5，洪水功能依次 75%／40%／0；低窪門檻乘 0.6。缺水 q 使用 severity=clamp((q−0.10)/0.75,0,1)，waterFactor=max(0,1−severity×敏感度)。敏感度住宅 .65、商業 .8、工業 1.15、農地 1.25、服務 .5。瞬時壓力=min(floodFactor,waterFactor)，不乘算，污染無直接扣功能。

存在任何功能壓力時不能恢復，只能維持或下降；壓力解除後每模擬秒恢復 1/60 功能。公共服務倍率=min(1.5,1+0.5×clamp(有效服務／目標,0,1))，使用當步受災後、恢復前服務快照。公共服務本身受災會降低加成；只影響恢復，不改排洪／供水／污染。輕／中／重度無加成約 15／36／60 秒，服務達標約 10／24／40 秒。再次受災中斷恢復；沒有永久毀壞或手動修復；同類點選不清除恢復記憶。

城市狀態按四類有效／需求比例（各封頂 1）的最低值：≥90% 良好、≥70% 受壓、≥40% 不足、更低嚴重失能；不是平均總分。主畫面有效值、受損保留已建名目；格子 ◐／⏸／↻ 與詳細資訊顯示受壓／失能／恢復。

## 設計原則：交接必讀

1. 韌性是功能掉得少、撐得久、恢復快，不是永久免疫。
2. 有水不等於可用水；低水位與污染都限制取水。
3. 正常蓄水不等於淹水災害；storage 與 surface 不混用。
4. 濕地不是無限處理廠；以廣大土地、合理串聯取得累積效果，不重洗靜止污染。
5. 處理廠單格高效但容量有限，且幾乎無滯洪、無生活功能；不新增金錢懲罰。
6. 公共服務只提高恢復，不產水、不排洪。
7. 自然解方／工程設施有不同角色，不能某設施全面最優。
8. 不做 Game Over；讓玩家觀察 → 討論 → 修改 → 再測試。
9. 不為增加難度將全圖變低窪或隨機全圖淹水。

## 已知限制與刻意延後

正式難度未校準；現在固定 12×10（120 格、90 可建、10 河川、20 道路）較未來多人 4×4 玩家地塊寬鬆，housing/jobs 容易達標，某些生活配置污染偏低、農地數值暫定。**現在不要為固定 12×10 地圖重調生活需求與污染難度；等 V2 玩家模組與共享城市完成再校準。**

污水真實回流會影響洪水，啟用污染後不能要求所有舊洪水結果相同。超長複合久旱會耗盡備援；4 分鐘 G/H 最低功能可能相同，但 G 首次失能较晚。正式複合回合可能停在豪雨末段，1C.2 全恢復時間使用明示 debug 小雨延長觀測，不能當成正式回合自動延長。

無真實供污管線、地下水、金錢、多人、正式講師控制台、正式部署。現有回合控制不是遠端課堂控制台。地圖／renderer 部分欄位仍依固定尺寸；引擎在單檔分段，尚非獨立模組。保留薄層水 surfaceRetention；不追求雨停瞬間全乾。土地更換免費、無施工時間；功能損失不反向減用水／產污。公園休閒不扣功能；城市狀態取最弱項。未宣稱跨所有瀏覽器或正式課堂規模驗證。

## 工程與驗收

正式來源 `water-resilience-p0.html` 內嵌 CSS／JS，依 config → data → engine → round controller → renderer → app 分段。engine 無 DOM；測試 loader 用 VM 取 renderer 前程式。雲端 README 提到 dist/build-offline/hosting，但本機沒有这些來源，不可照舊文件尋找或重建。Node v24.16.0 實測，无第三方依賴、不需 npm install。

fixed timestep .5 秒、double buffering、固定流向、共享接收能力、水量／污染帳本為已驗證核心。step 完成 waterSystemStep（含供水與污染）後更新單向功能 observer；observer 不改物理。正式 createSimulation 預設污染與韌性開啟；debug/engine-loader 預設兩者關閉以重現歷史回歸，新版必須明確開啟兩者。

11 個 test 檔，120 測試。涵蓋三種雨程／A～D、W1～W6、開局、供水／取水、P1～P8、濕地串聯／A～J、CITY-A～F、FUNC-A～H、守恆、重置／放置、倍速、pause/resume、開始播放。1×～4× 同排程固定步最終一致；暫停不推進模擬或恢復。1C.2 開關逐步物理狀態相同，關閉時與1C.1完整狀態相同。歷次實驗最大新案例水誤差約1.57e-8、污染3.99e-12。封版重跑記錄 `debug/v1-release-test-results.txt`；最終結果以該檔為準。

瀏覽器正式頁已驗證功能低點、自然恢復、服務足／不足、G/H、390px 手機與桌面，无 console error/warn，證據在1C.2報告與截圖。checkpoint 為來源回歸 fixture，不要因已有 Git 就刪掉測試引用；清單見 GITHUB-UPLOAD-CHECKLIST。

V2 可以抽出模組以解耦新 UI／流程／網路，但先說明理由、維持 API／每步結果、保留回歸對照；不得以換架構為由從頭重寫或重平衡。
